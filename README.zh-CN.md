# 景连 SMB · Studio 2.2

Windows 10 / 11 桌面共享管理器。基于 Python + CustomTkinter，调用 Windows 原生 SMB 接口；没有虚构在线状态或占位功能按钮。

## 使用

需要 Windows 和 Python 3.10+（建议 3.12），在此目录运行：

```powershell
python -m pip install -r requirements.txt
python smb-connect.py
```

一键生成便携版 EXE 和安装程序：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

在 Windows 上运行此脚本，产物位于当前目录的 `outputs`。应用和安装程序均为无控制台窗口构建，包含 PNG/ICO 资源。

随此源码另行交付的两个程序适用于 Windows 10 / 11 x64，均内置 Python 运行时。双击 `JingLink-SMB-2.2-x64.exe` 可直接启动。双击 `JingLink-SMB-2.2-Setup-x64.exe` 可安装到当前用户账户。两份 EXE 均未进行代码签名。升级安装前，请从系统托盘退出旧版。新版使用相同的用户配置目录，可读取旧版收藏。

## 界面语言

在「设置 → 界面语言」选择「中文」或「English」。应用立即更新菜单、按钮、诊断与新提示，下次启动会沿用选择。使用英文时，从 Settings → Display language 可切回中文。原有收藏和映射记录继续使用。Windows 提供的原生对话框或错误详情遵循系统语言。

## 2.1 新增操作

- 在「连接共享」点「粘贴地址」，支持带引号的 UNC 路径和 smb:// 地址，后者会转换为 Windows UNC。
- 「映射盘符」默认自动选择。Windows 报告盘符已占用时，尝试下一个可用盘符。仍可指定盘符。
- 勾选「连接后打开」可在映射成功后进入资源管理器。
- 「保存为收藏」和「我的连接 → 新建收藏」可在共享离线时保存路径。「最近连接」可将历史地址重新填入表单。
- 「测试可达性」显示主机解析、TCP 445 测试和检查提示，可点击「复制诊断」。
- 在 Windows 共享电脑上，可用「网络发现 → 查看本机共享」复制已发布的可见文件夹共享路径。

## 界面与功能

- 深青绿暗色 / 雾白浅色主题，主题持久保存；切换时保留连接表单。
- 概览网络数据流动画、悬停反馈；支持关闭动画，隐藏到托盘后停止绘制。
- 新品牌图标用于侧边栏、概览、关于页、窗口、托盘、EXE、安装器和快捷方式。
- 共享映射：UNC 地址校验，空闲盘符列表，可选账号、密码显隐、登录恢复映射。
- 端口诊断：解析地址、TCP 445 连通性及连接耗时；不会将端口可达伪装为共享认证成功。
- 映射列表：通过 WNetGetConnectionW 读取，包含不可用的持久映射；后台刷新，不阻塞 UI。
- 收藏管理：名称/地址/盘符编辑、删除、搜索、筛选、地址复制、快速填入连接表单。
- 最近连接：只记录真实成功的连接，支持清空。
- 设备发现：指定 IPv4 /24 网段、扫描进度、停止扫描、后台扫描、结果重入保留。
- JSON 收藏导入/导出：校验结构、限制体积、合并去重，仅导出名称/地址/盘符。
- 操作记录：本次会话最多 200 条，支持清空和导出文本。
- 托盘：关闭窗口收至托盘、手动收起、恢复、快速连接、刷新、退出。
- 自启动：当前用户 Run 注册表项，可选择后台启动；托盘就绪后才隐藏窗口。
- 快捷键：Ctrl+N 新连接、Ctrl+R 刷新、Ctrl+F 搜索、Esc 停止扫描。
- 安装器：当前用户安装、桌面及开始菜单快捷方式、卸载入口、卸载清理启动项。

默认配置位置 `%APPDATA%\JingSMB\connections.json`；目录无法写入时沿用原项目的临时目录回退机制。密码仅保留于本次连接的内存，不写入配置和导出文件。Windows 自身的凭据缓存由系统管理。

## 文件结构

- `smb-connect.py`：入口、Windows 映射接口与公共 UI 基础。
- `studio.py`：新版页面、交互、线程消息队列和托盘行为。
- `core.py`：共享/盘符校验、配置读写、Windows 映射读取。
- `setup.py`：品牌安装界面与安装/卸载。
- `assets/app.png`、`assets/app.ico`：多尺寸品牌资源。
- `previews/`：实际运行截图，NAS 地址是演示数据，不代表真实映射。
- `tests/`：核心回归测试及界面冒烟脚本。
- `VALIDATION.md`：已完成检查及 Windows 验收清单。
